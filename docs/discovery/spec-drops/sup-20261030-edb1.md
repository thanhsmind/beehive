Provenance: from waggledance@4462ca1, correlation id sup-20261030-edb1, 2026-10-30.

## The ask, as received

### Original (Vietnamese)

"thực hiện việc lấy chart, diagram, motion từ design-os qua bee-design cho
đầy đủ — không chỉ phần taste (đã có trong bee-design-charts /
bee-design-motion) mà cả các công cụ kiểm tra deterministic đi kèm."

### Translation

Bring chart, diagram and motion from design-os into bee-design in full —
not only the taste (already in bee-design-charts / bee-design-motion) but
also the deterministic check tools that go with it.

## Context from the originating session (measured 2026-10-30, main)

- bee-design-charts (35 files) calls `ui diagram` 35 times, `ui flow` 8,
  `ui chart` 5, `ui ds-usage-lint` 1.
- bee-design-motion (15 files) calls `ui taste-lint` 5, `ui tenant-lint` 4,
  `ui knowledge` 4, `ui gflow` 4, `ui scrub-scaffold` 2, `ui scrub-lint` 2,
  `ui tenant-scaffold` 1, `ui ds-usage-lint` 1.
- `bee-design/references/contract.md` allows only 13 commands, and
  `bee-design/SKILL.md` says "call nothing that is not there". The chart,
  diagram and motion packs tell a worker to call commands the core forbids.
- `bee design gate` wraps `ui gate` only. It does not run `ui chart`,
  `ui diagram`, `ui flow` or the motion linters, so a chart, diagram or
  motion artifact has no check in bee.
- ease-design 0.6.2 ships these subcommands (`ui chart`, `ui diagram`,
  `ui flow`, `ui tenant-lint`, `ui gflow`, `ui scroll-story`
  (informational), and more). Verify real flags with `ui <cmd> --help` on
  the pinned version.
- Related: PBI `sup-20261030-76ac` (pin 0.6.1 → 0.6.2) goes with or before
  this, because the new contract must match the pinned version. Upstream
  rewrote its history: `a7ad5f1` is gone from origin; the same content is
  `36033f2`.

## Wanted outcome (for this repo's chain to shape and plan)

1. `contract.md` (or one contract per pack) lists the chart, diagram, flow
   and motion commands each pack calls, with verified flags — no core vs
   pack conflict.
2. A check for chart, diagram, flow and motion artifacts in
   `bee design gate` (or an equal path with a baseline), and the UI cell
   cap rule knows about it.
3. Chart, diagram and motion taste in the packs syncs with upstream 0.6.2
   through `scripts/sync-design-os.sh`.
4. A real run on real data before done (for example anphabe-goglbe, which
   has the web and charts packs, and design-os `docs/examples`).

Afterwards the owner re-runs
`bee onboard --apply --design-packs web,charts,motion` in anphabe-goglbe.
That step is outside this run.

When bee needs to talk to waggledance, make the waggledance CLI the primary

## What waggledance now offers (waggledance main 601f92d, feature agent-cli)

Verbs on the `waggledance` binary:

| Verb | Shape |
| :--- | :--- |
| `projects` | list registered projects |
| `state [project]` | project state, or the all-projects rollup |
| `dispatch` | `--project P (--leader \| --preset L \| --pane-id ID)`; task from `--task`, `--task-file` or stdin; `--request-id`, `--follow-up-of`, `--handoff`/`--no-handoff`, `--steer` |
| `await <run_id> [--timeout S]` | wait for a run |
| `runs [--project P]`, `runs show <run_id>` | run list, one run |
| `task <corr> reply\|redo\|accept\|allow\|deny [--text T] [--req-id R]` | answer a task |
| `search "<intent>"`, `schema [verb]` | find a verb and its flags |

Output contract:

- JSON only: compact when piped, pretty on a TTY.
- A summary by default. `--full` prints the same `structuredContent` the MCP
  tool returns. `--fields a,b` keeps those keys per row. `--limit N` caps rows.
- A tool error prints to stderr and exits 1.
- Each verb calls the same handler as its MCP tool, so behavior matches MCP.

Measured on the owner's registry:

- All-projects state: 324,669 bytes over MCP, 6,796 bytes from the CLI.
- Run list: 587,737 bytes over MCP, 67,309 bytes from the CLI (750 bytes with
  `--limit 3`).

MCP payload changes in the same release:

- `waggledance_runs` rows carry `task_summary` instead of `task`. Pass
  `run_id` to get one run's full task.
- `waggledance_ask_state` without a project drops `sessions` and
  `recent_decisions` and adds `session_count`.

Binary name: the binary stays `waggledance`. `wg` is only an optional
user-made symlink (WireGuard owns `wg`). bee must not depend on a `wg`
command.

Reference docs in the waggledance repo: `README.md`, `docs/usage.md`,
`docs/waggledance-agents-template.md`,
`docs/waggledance-supervisor-skill-template.md`.

## Wanted outcome (for this repo's chain to shape and plan)

1. Where bee doctrine, skills, playbooks or code talk to waggledance, the
   `waggledance` CLI verb is the first path named.
2. The MCP tool stays named as the fallback when the CLI is absent or fails.
3. Nothing in bee calls or names a `wg` command.
4. Nothing in bee reads the removed `task` field of `waggledance_runs` rows or
   the dropped `sessions`/`recent_decisions` keys of the project-less rollup.

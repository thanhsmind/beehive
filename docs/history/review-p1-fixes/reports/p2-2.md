# p2-2 — Cache: allowlist proven-complete closures instead of guessing at incomplete ones

**[DONE]** — verify-cache caching is now opt-IN by declaration: a suite is cacheable only
if its entry file is declared in `scripts/verify-cache-inputs.json`; everything undeclared
is never read from and never written to the cache. The source-token heuristic
(`UNDECLARED_INPUT_TOKENS` / `mentionsUndeclaredInput`) and the `CACHE_OPT_OUT` set are
gone — the three reviewer-named escapees (`test_check_filter`, `test_workflow_step_paths`,
`test_herding`) no longer depend on being detected. Live repo split: **6 of 115 suite
entries cacheable, 109 uncached**, stated in every run summary as
`cacheable=<n>/<total> declared (<n> uncached)`.

Files touched:
- `scripts/run_verify.mjs`
- `scripts/tests/test_verify_cache.mjs`
- `scripts/verify-cache-inputs.json` (new — the declaration table)

Full trace, verify evidence and deviations: `.bee/cells/p2-2.json`.

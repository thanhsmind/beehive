## Feature Boundary

Every bee rule governs *process*; none governs what a change leaves behind. A
worker that threads a flag through five layers, keeps a compatibility shim and
adds a fourth boolean passes every gate, because green tests and an honest cap
are the whole bar. This feature puts four code-shape rules where a worker reads
them at the moment it writes code — the dispatch brief. It ends there: no new
guard, no new refusal, no rule about types or domain modelling.

## Locked Decisions

| ID | Decision | Rationale |
|----|----------|-----------|
| D1 | The rules go in the WORKER BRIEF, not in `AGENTS.md`. | The user's call, and the xia's own evidence supports it over its own recommendation: it ranks placement "bee's refusing hooks > pstack's step-cited principles > bee's always-loaded contract middle > bee's 173-pattern archive", and says bee "already believes this — its dispatch pipeline and skill routing are exactly that mechanism". A contract line is a tax on every session and sits in the part the xia says decays; the brief is read at the moment of use and costs nothing to a session that dispatches no worker. |
| D2 | Four rules, no more: prefer deletion before addition; the smallest diff that solves it; a signal threaded through several layers means stop and find the direct path; leave the base simpler than found. | The xia's own list, and its own boundary — "the rest of pstack's code-quality cluster (types, domain modelling, reader load) is too large for the contract". Four lines is the whole scope. |
| D3 | Nothing refuses. These are craft applied by judgment and surfaced at review, exactly like the existing red-before-green rule at `worker-details.md:33-35` ("not by flags"). | bee already has one code-craft rule and it deliberately carries no teeth. A second one with teeth would be an inconsistent pair, and "leave the base simpler than found" is not mechanically checkable. |
| D4 | The edit lands in the SOURCE, `packages/bee/prompts/worker-cell.md`, never in the installed copy at `.bee/bin/prompts/worker-cell.md`. | The installed copy is regenerated by `bee onboard --apply`, which silently discards a direct edit. This exact trap cost a worker a lost edit under `.bee/expertise/` earlier today; the reflection is recorded. |
| D5 | No `expertise/rust.md` in this feature. | The xia offers it as "if it is wanted at all". It is a separate, larger question and is not smuggled in behind a four-line change. |

# Approach: Codex parity completion

Document mode: explanation.

## Recommended path

D1 uses the existing Rust guard, role resolver and transcript consumers. Correct the host projection before claiming source behavior reaches users. Use an enforced read-only CLI boundary where native spawn cannot narrow permissions.

## Alternatives

A second runtime policy engine would duplicate rules. Prompt-only read restrictions would not satisfy the requested enforcement. Unsupported event names would produce false coverage.

# Plan: cut token spend in bee-driven projects

## Summary

Five owner-approved cuts from the survey-platform evidence (CONTEXT.md D1 to
D5): a leader hands off at a 300k mark and after each merge, test and small
design run on sonnet, workers read ranges instead of whole files, the worker
brief loses the index.md fallback and half its knowledge budget, and small
standard-lane cells skip the semantic judge.

Mode: `standard` — three small code changes in three disjoint files, one test
cell, doctrine text that every project receives on refresh.

## Requirements (from CONTEXT.md)

- D1: default mark 300000; directive line; merge next action names the handoff.
- D2: plan-time escalation for hard test and substantial design cells; stack-neutral role text.
- D3: read rule in every worker agent template.
- D4: no index.md fallback; lane budgets halved.
- D5: standard-lane judge skip under 30 changed lines; tester returns the judge block.
- C1, C2, C3: contracts handoff-mark-directive, knowledge-pack-budget, judge-small-diff.

## Approach

Situation: `skills/bee-planning/playbooks/feature/feature.md`. architect
skipped: each change is a constant, a line of text, or one filter over an
existing loop; no new data shape. The judge skip reads a number the cap
stores (`trace.changed_lines`), so close never runs git.

Throughput checkpoint:
- Blocking first steps: none; the gate runs before fan-out.
- Independent workstreams: tsc-1, tsc-2, tsc-3 touch disjoint files and run at once.
- Shared mutable state: tsc-5 renders skills and agents (one regen root), so it runs after the code cells and alone.
- Smallest safe decomposition: one tester (tsc-4) for three small code cells, because each contract is a handful of cases.

Rejected: a new design-light role (escalate already exists); counting lines at
close with git (the cap commit may be rebased; the cap knows it once).

## Risk map

| Risk | Guard |
|---|---|
| A leader hands off mid-cell at the mark | The line says the next clean stop: a capped cell or a merged worktree |
| A large cell slips under the judge skip | The cap counts every file of its commit; absent count means the cell owes a verdict; high-risk unchanged |
| A worker misses knowledge it needs after the budget cut | The manifest still ranks by relevance; workers keep `bee knowledge search` |
| Rendered agents drift from templates | tsc-5 builds the binary and runs `bee dev regen`; the agent drift tests run in its verify |

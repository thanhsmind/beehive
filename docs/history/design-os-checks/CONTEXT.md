## Feature Boundary

bee-design moves to ease-design 0.6.2; every pack that tells a worker to run
a `ui` command gets its own generated command contract; `bee design gate`
also checks chart, diagram, flow and motion artifacts against the baseline;
the UI cap rule counts flow files as UI files. It ends at this repo: the
consumer project's own re-install and baseline are the owner's acts there.

| D6 | `bee design gate` finds artifacts by what upstream's linters key on, with no new config: an HTML page carrying `data-chart-owned="true"` runs `ui chart lint`; `data-diagram-owned="true"` runs `ui diagram lint`; a page with an element of class `scrub` runs `ui tenant-lint`; a file named `flow.json` or `*.flow.json` runs `ui flow lint`. HTML artifacts come from the same page set as `ui gate`; flow files from the same walk. | A chart lint on an ordinary dashboard page errors (`svg-owned-count`), so artifacts must be picked by marker. |
| D7 | Artifacts ratchet like pages: the baseline gains an `artifacts` map (kind, then path, then errors and warnings). A known artifact may not gain errors; an artifact with no baseline entry must have 0 errors. A project with no artifacts sees no change in output. | — |
| D8 | `ui scrub-lint` (encoded clips) and `ui scroll-story` (informational upstream) stay out of the gate. Both are in the motion contract for manual use. | No marker tells a scrub clip from any other video. |
| D9 | The baseline records which `ui gate` families it counted. The gate compares only the error count of those families; a baseline with no family list counts the 0.6.1 set (a11y, autofix, content, layout, taste, tell). When the run has families the baseline lacks, the gate prints one line naming them and the re-record command; it does not fail on them. Without D9 the bump fails every UI cell in every host until a person re-records. Named guess under gate bypass full. |

# doc-impact-synthesis — plan (v2)

**Lane:** standard · **Route flags:** data-model (decisions event gains
`feature`), covered-contract-change (close doors, decisions log) ·
**Files:** ~11 product
**v1 rejected by plan-check** — impact-door self-hit on the generated
decisions index (2-of-2 hits in a live probe), dead-end stub remedy,
grammar gaps, unbounded fallback window, undefined git base. v2 answers
each finding.

## Goal

Impact-driven doc maintenance on the phase-1 substrate: touched decisions
find their citing docs and force the fix (D1), locked CONTEXT decisions
synthesize into area specs (D2), deferral prose in docs joins the trigger
registry (D3), then one bounded backfill proves the doors (D4).

## Shape — slice 1: 3 sequential cells (kds-1 → kds-2 → kds-3)

Sequential by named reason: kds-2 needs kds-1's `feature` field; kds-2 and
kds-3 both edit `drivers/close.rs`.

### kds-1 — log-time impact walk + feature linkage (D1a)

Files: `verbs/decisions/verbs_read.rs`, `verbs/decisions/tests.rs`,
`docs/knowledge/areas/decision-memory/overview.md` (schema-surface sync —
data-model doctrine) (+ read-only reuse of
`render.rs::sweep_decision_citations`, def at `render.rs:419`).

- After the event append (seam: post-`verbs_read.rs:634` append, `touches`
  full ids and the new id in scope at `:640`), run
  `sweep_decision_citations(root, id, short8)` for EACH resolved
  `touches:` id, EXCLUDING hits in `docs/decisions/index.md` (generated —
  regenerated by `decisions render`, never hand-fixed) and
  `docs/history/<the-logging-feature>/` when a feature is bound
  (self-citation of live work is not staleness). Each surviving hit
  enqueues a capture stub (`add_capture_stub` shape, `supersede.rs:56-85`)
  with `source: "touches-sweep"`. Supersede's own sweep stays untouched.
- Stamp `feature` on every new `decide` event: derived from the calling
  context's active feature (session-bound-lane-else-default, as
  `state route` resolves); no resolution → no field. Legacy lines
  unchanged; readers tolerate absence.
- Sync the event-schema surface in decision-memory/overview.md (the new
  `feature` field, one data-dictionary line).
- Tests: touches log enqueues one stub per citing file; index.md and own
  history hits excluded; no touches → no sweep; `feature` present when
  bound, absent otherwise; supersede sweep unchanged.

### kds-2 — impact door at close (D1b)

Files: `verbs/drivers/close.rs`, `verbs/drivers/tests.rs`.

- `build_impact_door`, stub-independent (v1's flush-coverage design was a
  dead end — hits written after log time never had stubs): collect the
  closing feature's decision ids from the structured `feature` field ONLY
  (kds-1 lands first, so every decision of this and later features
  carries it). Named deviation, recorded here: pre-kds-1 decisions are
  not walked at close — the 2026-08-16 audit backfill (kds-4) and the D4
  campaign row own that debt; a time-window fallback was rejected as
  unboundable (plan-check S2).
- For each id: `sweep_decision_citations`, then EXCLUDE
  `docs/decisions/index.md`, `docs/history/<closing-feature>/`, and
  generated trees (the write-guard's generated-tree list). Every
  surviving hit blocks close, detail naming file:line + the remedy: fix
  the citing doc (or supersede/annotate it), re-run close — the sweep
  re-runs fresh each close, so a fixed doc clears itself. Recorded-
  deferral escape, same shape as the freshness door
  (`has_knowledge_freshness_deferral_decision`, `close.rs:687`).
- Door slots after knowledge-freshness: exit chain (`close.rs:1403-1418`
  region) + all three doors vecs (`close.rs:1182,1232,1301`) + the
  refusal branch.
- Tests: outside-doc citation of a feature decision → refuses naming
  file:line; fixing the doc clears on re-run; index.md/own-history hits
  never block; deferral demotes with reason; feature with no
  field-stamped decisions → clear.

### kds-3 — routing + doc-deferral doors (D2, D3)

Files: `verbs/drivers/close.rs`, `verbs/drivers/tests.rs`, CONTEXT-table
parser (`verbs/drivers/context_table.rs`).

- **Routing door (D2)**: parse `docs/history/<feature>/CONTEXT.md`:
  heading `## Locked Decisions`, first following pipe-table whose header
  row STARTS WITH `| ID | Decision` (prefix-tolerant — the canonical
  3-column template header at
  `skills/bee-shaping/references/context-template.md:26` parses; so does
  this feature's own CONTEXT), rows `| D<n> | ... |`.
  - Parseable table: each D-ID is routed when the bundle
    (`docs/knowledge/`) carries `<feature-slug> D<n>` in plain, range
    (`D1-D3`), or slash-list (`D1/D3`) form, OR the decision's logged
    short8, in body or frontmatter `decisions` list — or a logged
    decision tagged `feature-local` names `<feature-slug> D<n>`.
    Unrouted D-IDs block, detail listing both remedies. Multi-area
    routing (cited in >1 area) is a report-only duplication warning, not
    a block — named deviation from D2's "exactly one": presence is the
    law's teeth, cardinality is grooming's hunt.
  - No canonical table (legacy bullet/split forms, 63 of 112 current
    files): LOUD report-only notice naming the gap and the campaign row —
    named deviation from D2's letter, bounded by D4's
    no-archaeology rationale: the door BLOCKS only for CONTEXT files
    carrying the canonical grammar (every post-door shaping does — the
    template is the grammar).
- **Doc-deferral door (D3)**: scan set = the closing feature's capped
  cells' `files_changed` filtered to `docs/` UNION
  `docs/history/<feature>/` (CONTEXT.md is written at shaping, before
  cells exist — `feature_touched_files`, `close.rs:980-995`, alone would
  never see it). FULL-TEXT scan of that bounded set — no git diff: close
  spawns no git today and a merge-flow base is ill-defined post-merge
  (plan-check S2); named deviation from the diff-only idea. A line
  matching `matches_deferral_prose` (`verbs_read.rs:340`, pub(crate))
  without a same-line trigger citation (backtick trigger id or
  `[[trigger:<id>]]`) resolving via `trigger_registered()`
  (`triggers/mod.rs:278`) blocks with the create-the-trigger teach line.
  Lines inside code fences are skipped.
- Both doors: recorded-deferral escape, same shape; slot after impact.
- Tests per door: canonical table routes (plain, range, slash forms);
  legacy CONTEXT → loud notice, no block; unrouted blocks;
  `feature-local` tag clears; multi-area → warning only; deferral line
  without trigger blocks / with registered trigger clears; fenced code
  never trips; this feature's own CONTEXT parses.

## Cost if wrong

- kds-1 additive; rollback = skip sweep, drop field writes.
- kds-2/kds-3 doors over-block → per-door recorded-deferral escape and a
  one-bool demotion, phase-1 precedent. The canonical-grammar bound keeps
  the routing door from taxing the 63 legacy CONTEXT files.
- Exclusion lists under-exclude → a false block names its file:line; the
  deferral escape is the pressure valve while the exclusion is widened.

# docs

Prose a reader acts on, or a skill an agent follows: pick the situation below and open its file.

## Situations

- `docs` — docs, documentation, README, guide, handbook, knowledge, update the docs, tài liệu, viết tài liệu, cập nhật tài liệu, doc lệch code — delivers: the document extended where it lives, every path and command in it resolved, and the parity or pointer check that ran
- `authoring-a-skill` — new skill, edit a skill, SKILL.md, skill description, agent-facing prose, viết skill, sửa skill, tạo skill mới — delivers: the skill written in the owner's voice, validated, and landed through the bee close and merge path

No situation fits, or the work is large and cross-cutting: use bee-figure-it-out.

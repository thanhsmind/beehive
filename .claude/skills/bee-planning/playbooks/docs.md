# docs

1. Read what the bundle already holds for the area before writing a line — you
   cannot extend a document you have not found.
2. Extend the document that owns the area — a near-duplicate filed beside it
   splits one truth into two that drift apart.
3. Decide which side is wrong — the doc or the code — and fix THAT one.
4. Resolve every path and command you write, because a dead pointer sends the
   next reader astray: open it, or run it.
5. Prove with parity and pointer checks, not with tests — a test never reads
   the prose it would have to catch.
6. Name what is still uncovered, so that the reader knows where the doc stops.

A second document saying the same thing is not coverage.

Proof line: the parity or pointer check that ran, and its output.

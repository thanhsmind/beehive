# bee-design-apple — the native Apple pack

Project type: native SwiftUI apps on iPhone, iPad and Mac. This pack adds that taste to `bee-design`.
Load `bee-design` first for its concept, rules, path names and hand-over; its web gate does not check a
native screen, so name what you could not verify. When `bee-design` is not installed, say so.

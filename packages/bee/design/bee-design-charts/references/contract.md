## ui ds-usage-lint

Check a UI source file (or a directory of them) against the project DS's declared tokens and fonts; exit 1 on error-severity findings

Usage: `ui ds-usage-lint <file|dir> [flags]`

| Flag | Type | Meaning |
| --- | --- | --- |
| `--dir` | string | Project directory holding design/ (default: cwd) |
| `--tokens` | string | DTCG token file to lint against instead of <dir>/design/design.tokens.json |

Error codes: `BAD_ARG`, `FILE_NOT_FOUND`, `READ_ERROR`, `DS_NOT_FOUND`, `BAD_JSON`, `NO_UI_FILES`, `NO_FILES_READ`

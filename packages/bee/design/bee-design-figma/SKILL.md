# bee-design-figma — the Figma pack

Project type: design work done in Figma, and projects whose design system lives in Figma. This pack adds
that taste to `bee-design`. Load `bee-design` first: its taste rubric and path names apply here, and a
render built from a Figma frame comes back to its Check step. When `bee-design` is not installed, say so.

| Need | Read |
| --- | --- |
| Figma craft: start at the entry file, then the topic you need (layout, components, variables and styles, structure hygiene, visual craft, Code Connect, workflow) | [figma-craft/figma-craft.md](references/figma-craft/figma-craft.md), the rest of [figma-craft/](references/figma-craft/) |
| Drive the figma-agent CLI, the optional Figma hand | [figma-agent-hand.md](references/figma-agent-hand.md) |
| Install and verify the design:os Figma plugin, then read an owner's design system into local stores | [figma-ds-onboarding.md](references/figma-ds-onboarding.md) |

# bee-design-web — the web pack

Project type: web pages and web apps. This pack adds web taste to `bee-design`. Load `bee-design` first:
its workflow, rules, path names and gate check apply to every page you build with this pack. When
`bee-design` is not installed, say so.

| Need | Read |
| --- | --- |
| Pick one or two purposeful web craft mechanisms for a brief, with their safe implementation contract | [web-technique-craft.md](references/web-technique-craft.md) |
| The technique catalog and its cards (3D worlds, content and proof, layout and surface, real-time fields, scroll storytelling, semantic motion, system quality) | [web-techniques/](references/web-techniques/) |
| What an archetype (pricing, checkout, login, settings) looks like across observed product screens | [pattern-cards.md](references/pattern-cards.md), cards in [patterns/](references/patterns/) |
| The one memorable gesture a persona layers on top | [signature-devices.md](references/signature-devices.md) |
| The DESIGN.md contract: YAML token front matter plus the eight fixed sections | [designmd-format.md](references/designmd-format.md) |
| Build, verify and adopt an owner component kit on React, shadcn and Tailwind | [ds-kit-onboarding.md](references/ds-kit-onboarding.md) |
